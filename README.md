**Desenvolvedora de Software | Backend, Cloud e visão de produto**

Eu desenvolvo software de backend e cloud e começo pelo problema antes do código. Já entreguei APIs REST, sistemas de autenticação e multi-tenancy e fluxos serverless na AWS com IA, e fiz isso sob pressão de tempo real, em hackathons em que o objetivo é sair de uma ideia vaga para algo que as pessoas conseguem usar de verdade.

Meu caminho é um pouco diferente do comum: sou bacharel em Turismo, construí minha trajetória em atendimento ao público e depois migrei para software, com formação Full Stack, residência técnica, projetos colaborativos e muitos hackathons. Essa bagagem influencia muito o meu jeito de trabalhar: eu penso em quem é o usuário, qual é a dor dele e qual é a menor versão útil que resolve o problema.

## ✨ O que eu levo para o time

- **Visão de produto, além da implementação.** Uso Lean Inception para alinhar o time sobre o problema, a persona e o MVP antes de abrir o editor. No hackathon Artemisia × Ada Tech, meu time foi o único a levar storytelling centrado no usuário e um processo ágil visível para o pitch.
- **Spec-driven development com agentes de IA.** Escrevo especificações claras, user stories e critérios de aceite, construo com agentes de IA a partir delas, e reviso, testo e respondo pelo que vai para produção. É assim que um time pequeno consegue ser rápido sem perder estrutura.
- **Base sólida em backend e segurança.** Autenticação, autorização, JWT e multi-tenancy são onde eu me sinto em casa.
- **Cloud e IA aplicada.** Arquiteturas serverless na AWS, processamento de documentos com Textract, LLMs no Bedrock, RAG e pipelines orientados a eventos.
- **Comunicação.** Sei explicar uma decisão técnica para um colega, uma mentora ou uma banca, e assumo o trabalho de "cola" (spec, QA, demo) que faz um projeto de fato chegar ao final.

## 🚀 Projetos em destaque

### 🏆 Extrato Popular — Insights financeiros com IA para consumidores de baixa renda

**1º lugar | Hackathon Artemisia × Ada Tech (Elas+ Tech)**

Plataforma com RAG que transforma dados financeiros confusos em orientações em linguagem simples para pessoas que costumam ficar de fora das fintechs. Time de quatro pessoas.

- Responsável por **autenticação, segurança e multi-tenancy** (Java 21, Spring Boot 3, Spring Security, JWT).
- Conduzi uma **Lean Inception** enxuta e mantive o produto centrado no usuário final, quem usa e paga pela solução; a nossa persona foi o fio condutor do storytelling no pitch final.
- Entreguei **297 testes automatizados com 95,2% de cobertura de código** (JaCoCo) e **93,3% de conformidade** com os critérios de avaliação do edital.

**Stack:** Java 21 · Spring Boot 3 · Spring Security · JWT · Multi-tenancy · RAG

### 📄 DocuSmart Seguros — Processamento de sinistros de seguros na AWS

**Hack2Hire | Escola da Nuvem (EDN)**

Solução serverless ponta a ponta que automatiza a entrada e a triagem de sinistros, com portal do cliente e portal do analista. A IA resume cada sinistro para que um analista humano aceite, negue ou escale o caso, mantendo uma pessoa na decisão.

- Depois que o time caiu de cinco para uma pessoa, assumi a **especificação técnica (16 páginas), a arquitetura, o QA e a demo final**.
- Desenhei o fluxo com **Amazon Bedrock (Nova Pro)**, **Strands Agents**, **Textract**, **SQS com dead-letter queues**, **API Gateway**, **S3** e **DynamoDB**.
- Escrevi jornadas de usuário, regras de negócio e user stories com critérios de aceite, e executei testes end-to-end.

**Stack:** AWS Lambda · Bedrock · Strands Agents · Textract · SQS/DLQ · API Gateway · DynamoDB · S3

### ⚡ Agents for Ecommerce — Pipeline orientado a eventos com LLM

**Hackathon deco.studio**

Pipeline orientado a eventos construído com **Cloudflare Workers e Queues**, um serviço em **NestJS** rodando em **Docker** e integração de LLM com **Gemini**.

**Stack:** Cloudflare Workers · Queues · NestJS · Docker · Gemini
